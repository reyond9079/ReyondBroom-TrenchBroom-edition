# FTEBroom — экспериментальный редактор внутри FTE

[English](README.md) · [Руководство](ftebroom/README.ru.md)

Независимая ветка разработки редактора на движке FTE Quake, csaddon и Dear ImGui. Цель — перенести основные сценарии ReyondBroom внутрь движка.

**Версия 0.1 — прототип, полного соответствия ReyondBroom пока нет.** Реализованы нативная панель, создание куба по размерам, история брашей, сетка, виды и команды сохранения/открытия MAP. Сценовые инструменты csaddon остаются доступны. Процедурные инструменты и физика ещё не перенесены.

Сборка, запуск и список проверок: [руководство](ftebroom/README.ru.md). План переноса: [архитектура](ftebroom/ARCHITECTURE.ru.md). Код: [ftebroom](ftebroom/).

Остальные исходники репозитория сохранены как справочная реализация ReyondBroom. Его Qt/CMake-сборка не собирает FTEBroom; используйте отдельный скрипт из руководства. Стабильная ветка и релизы ReyondBroom не изменяются. Новый код FTEBroom — GPL-2.0-or-later; лицензии сторонних компонентов сохранены.
